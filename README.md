## 🧪 Proyecto principal — Pixel Size

### The Real Size of the Pixel

**Pixel Size** es un proyecto de videojuego experimental centrado en la exploración y simulación a diferentes escalas.

La idea gira alrededor de un universo 2D en el que el jugador puede viajar progresivamente entre diferentes dimensiones de escala.

Desde:

**🌌 Universo**

↓
**🌀 Galaxias**

↓
**☀️ Sistemas solares**

↓
**🌍 Planetas**

↓
**🏙️ Ciudades**

↓
**🧍 Humanos**

↓
**🧬 Biología**

↓
**⚛️ Átomos**

El objetivo es crear una experiencia en la que el zoom y la escala sean parte fundamental de la jugabilidad y de la exploración.

## 📱 Responsive & Accessibility

La web está preparada para diferentes tamaños de pantalla:

```text
Desktop
Laptop
Tablet
Mobile
```

También incluye diferentes mejoras de accesibilidad:

* Navegación mediante teclado
* Estados `focus-visible`
* Skip link
* Botones y enlaces claramente identificables
* Soporte para `prefers-reduced-motion`
* Estructura semántica
* Diseño adaptable

Las animaciones se reducen automáticamente cuando el usuario ha configurado su dispositivo para minimizar el movimiento.

## ⚡ Rendimiento

La web intenta mantener las animaciones y efectos visuales bajo control para evitar cargar recursos innecesarios.

Se utilizan principalmente:

* CSS animations
* Transforms
* Opacity
* Intersection Observer
* JavaScript ligero
* Efectos activados únicamente cuando son necesarios

La intención es conseguir un equilibrio entre:

**Visuales ↔ Interacción ↔ Rendimiento**

## 🌍 Publicación

El proyecto puede publicarse fácilmente mediante **GitHub Pages**.

### 1. Crear un repositorio

Crea un repositorio en GitHub, por ejemplo:

```text
axiii-portfolio
```

### 2. Subir los archivos

Sube:

```text
index.html
style.css
script.js
```

Los tres archivos deben estar en el mismo directorio.

### 3. Activar GitHub Pages

En GitHub:

```text
Settings
↓
Pages
↓
Build and deployment
↓
Deploy from a branch
↓
main
↓
/ (root)
```

Después de guardar, GitHub Pages generará la página pública del portfolio.
